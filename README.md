# mac-flasher

mac-flasher is a tool for flashing ISO images on macOS.

# Versions

- **AppleScript version** - easier to use
- **Bash version** - harder to use, but provides some progress information. **Recommended**

# Supported ISOs

- BSD
- Linux
- Windows
- Android x86
- Recovery ISOs

# Current limitations

- No native GUI
- CDs
- macOS recovery images

# Dependencies

- bash
- diskutil
- dd
- hdiutil
- rsync
- awk
- sed
- grep
- stat
- wimlib
